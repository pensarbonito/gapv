# 🚀 Workspace Dashboard

Dashboard ultra ligero y sin dependencias para la gestión local de tareas y proyectos. Funciona 100% en el navegador usando HTML, CSS y JavaScript nativo.

---

## ✨ Características

* **Persistencia Local:** Guarda datos en `localStorage` (no pierde información al recargar o cerrar el navegador).
* **Diseño Responsive:** Adaptado para escritorio y móviles.
* **Respaldo CSV:** Exporta e importa tus tareas para compartir o restaurar copias de seguridad.
* **Organización:** Filtros por categorías, proyectos y asignación por colores para cada integrante o "Todo el equipo".
